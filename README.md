# 关西旅行攻略

巴图推荐 · EasyGo!

独立静态网页。入口是 `index.html`，无需安装依赖、构建、外部字体、CDN、API、账户或付费服务。请仅放入本项目专用的新仓库，不要覆盖其他项目。

## 打开与发布

- 本地：解压后，用浏览器打开 `index.html`。请保留同目录的 `style.css`、`app.js` 与 `assets/`。
- 静态托管：将本目录原样作为站点根目录。路径为相对路径，可用于 GitHub Pages 项目子路径。
- GitHub Pages：在一个新的独立仓库内上传本目录的文件，再选择存放文件的分支及根目录作为发布来源。此交付包没有创建仓库或开启部署。
- 不需要 npm、构建命令、后端、数据库或秘密凭证。

## 页面内容

- 原版封面完整显示；14 张原图均保留原字节，未重绘条码和二维码。

## 资料与边界

门店名称与地址核对日期：2026-10-09。来源可在网页“资料来源与出行前确认”中查看，另见 `destinations.json`。
